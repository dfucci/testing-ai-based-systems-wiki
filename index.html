Metamorphic testing

Page Description

Robustness and test generation

Page Description
AORTA (Xiao 2025) Black-box adversarial robustness testing jointly perturbing prompt+example, Adaptive Beam Search
ABFS (Xiao 2026) AORTA successor; Best-First Search over a confidence-keyed priority queue + adaptive WIR; +6.248pp success rate, PPL 8.161 lower
REAG (Wang 2026) Requirements-grounded oracle generation + calibrated LLM-judge cascade for acceptance testing
Adaptive Testing (Yoon 2025) Diversity-based test selection for prompt templates under a query budget
ConcoLixir (Chen 2026) LLM as reactive “discovery oracle” for Python concolic testing; +8.6-17.0pp line coverage
Intent-Based Mutation Testing (Hamidi 2025) Mutate NL intent, not syntax; 55% of mutants not subsumed by traditional mutation
MuMuTestUp (Tian 2026) Mutation-guided multi-agent framework for updating outdated test cases across PRs
STELLAR-D (Sorokin 2026) Genetic search-based LLM-app test generation with an archive-based diversity objective; greedy repopulation best balances failure detection and diversity
Test-Aware Mutants (Kiele 2026) LLM sees the base tests and must write a subtle bug that passes them; 87.8% verified-fault rate on HumanEval vs. 12.2% test-blind, 4.4% mutmut

Oracle construction and auditing

Page Description
Delta (He 2026) Self-referential differential testing for DRL optimality bugs via an offline-RL-trained challenger
FOCAL (Zhao 2026) Learned discriminative PASS/FAIL oracle; exposes hidden failure-detection blind spots in baselines
Auditing Feedback-Driven Evolution (Liang 2026) Shows single-reference pseudo-oracles inflate apparent LLM test-generation gains by 9-15pp
Oracle Conversion (Liang 2026) Splits potential vs. effective kill; correctness-only reward narrows discriminative-input selection
Mubric (Yang 2026) Mutation testing applied to rubrics: inject defects into a reference response, refine rubrics that fail to penalize them; 57.27% vs. 49.78% best baseline
