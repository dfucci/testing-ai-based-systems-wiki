Motivation

Validating clustering (unsupervised ML) is hard for two reasons: there’s no ground truth to check against (the oracle problem), and existing validation techniques (external/internal indices) evaluate a clustering result only statically — they ignore how results should change when the input dataset is transformed, even though users have intuitive expectations about that dynamic behavior. (source: METTLE)

Approach

Users (not necessarily ML experts) define metamorphic relations (MRs) between an original dataset/clustering and a transformed follow-up dataset/clustering. The paper contributes 11 generic MRs across 6 categories: object ordering, cluster distinctness (shrinking/mirroring), object density, attribute manipulation, coordinate transforms (rotation/scaling), and outlier handling.

Two metrics quantify violations:

  • Reclustering percentage (RP) — fraction of objects reassigned inconsistently between source and follow-up outputs.
  • Violation rate (VR) — fraction of trials violating an MR.

MR compliance becomes a property-oriented adequacy criterion (see Test Adequacy Criteria) for selecting the most appropriate clustering system for a given context, with user-assignable per-MR weights.

Results

Six Weka clustering systems tested (k-means, x-means, EM, agglomerative nesting, farthest-first, DBSCAN) across 11 MRs × 100 trials. K-means was most sensitive (violated 9/11 MRs); agglomerative nesting was most robust (3 violations). Five recurring violation patterns identified: BORDER, MERGE&SPLIT, SPLIT, NOISE, NUM. Root causes traced to concrete implementation details — e.g. min-max normalization caused all systems to violate a rotation-invariance MR despite rotation invariance being mathematically expected, and k-means/EM got trapped in local optima.

A 15-participant user study (7 application domains) found users could define domain-specific MRs themselves, and METTLE’s system rankings largely matched user preferences — participants reconsidered agglomerative nesting after seeing its strong MR compliance.

Relation to broader wiki

Fills a real gap flagged by Zhang et al. 2022: only 3/144 surveyed papers address unsupervised learning testing at all. Extends prior MT work on supervised classifiers, search engines, and deep-learning image classifiers (DeepTest/DeepRoad) into the unsupervised setting.
