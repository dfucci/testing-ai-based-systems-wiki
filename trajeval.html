Overview

TRAJEVAL addresses a fundamental limitation of outcome-based evaluation: Pass@1 collapses entire execution into a single binary signal, making it impossible to identify where or why an agent fails. (source: Kim et al. 2026)

The framework decomposes agent trajectories into three sequential stages and computes precision/recall at each by comparing against a golden context derived from reference patches.

Three-Stage Decomposition

(source for all three stages: Kim et al. 2026)

Stage 1: Search (File-Level)

Measures the agent’s ability to localize the relevant files.

  • Precision Ps = |F* ∩ FT| / |FT| (fraction of viewed files that were necessary)
  • Recall Rs = |F* ∩ FT| / |F*| (fraction of necessary files that were viewed)

Stage 2: Read (Function-Level)

Measures whether the agent examined the relevant functions within those files.

  • Precision Pr = |H* ∩ HT| / |HT|
  • Recall Rr = |H* ∩ HT| / |H*|

Stage 3: Edit (Function-Level)

Measures whether the agent’s modifications targeted the correct code locations.

  • Precision Pe = |H* ∩ Hp̂| / |Hp̂|
  • Recall Re = |H* ∩ Hp̂| / |H*|

Edit metrics capture localization accuracy only. Semantic correctness is evaluated separately via Pass@k.

Key Empirical Findings

(source for this section: Kim et al. 2026)

Universal over-exploration

Across all models and architectures, precision is uniformly low (4–8%). Agents examine 8–12× more files and 17–25× more functions than necessary. Current agents trade efficiency for coverage.

Recall predicts success; precision does not

Logistic regression coefficients: edit recall (β̄=1.22) > search recall (β̄=0.90) > read recall (β̄=0.78). Precision coefficients are near zero across all stages. An agent that reads every file but edits the right location succeeds; an efficient agent that edits the wrong location fails.

Distinct model failure modes

Different models exhibit diagnosably distinct failure patterns — see Agent Failure Modes.

Actionable diagnostics

Real-time feedback (“you are examining relevant code for this issue”) injected when agents view golden-context files improves Pass@1 by 2.2–4.6 percentage points while reducing token costs by 20–31%.

Prediction Accuracy

Six trajectory features (Ps, Rs, Pr, Rr, Pe, Re) fed to a per-model logistic regression classifier predict model-level Pass@1 within 0.87–2.1% MAE. Ranking correlation ρ ≥ 0.886 is preserved under repository-held-out and language-held-out distribution shifts. (source: Kim et al. 2026)

Experimental Scope

Evaluated 16,758 trajectories across (source: Kim et al. 2026):

  • Three agent architectures: SWE-Agent, OpenHands, LiveSWEAgent
  • Seven models: GPT-5, GPT-5-mini, Qwen3-8B, Qwen3-32B, Qwen3-235B, Qwen3-Coder-30B, Qwen3-Coder-480B
  • Two benchmarks: SWE-bench Verified (500 Python issues) and PolyBench Verified (382 multilingual issues)

Relation to Prior Work

Traditional benchmarks measure outputs. TRAJEVAL measures process. It complements agent development by explaining why one agent outperforms another, not just that it does. (source: Kim et al. 2026)
