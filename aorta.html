Summary: First automated black-box robustness-testing framework to jointly perturb prompt and example inputs for LLM-based NLP software, using a novel Adaptive Beam Search that beats prior adversarial attacks on success rate, efficiency, and output naturalness.

Sources: Xiao et al. - 2025 - Assessing the Robustness of LLM-based NLP Software via Automated Testing.pdf

Last updated: 2026-08-19

Motivation

LLM-based NLP software (financial sentiment analysis, toxic-content moderation, etc.) relies on prompt+example input, not trained weights — no automated robustness-testing framework existed for the combined prompt+example input space. Prior work tested prompts and examples separately, or reused DNN-testing methods that transferred poorly. (source: Xiao et al. 2025)

AORTA framework

Reframes robustness testing as combinatorial optimization over four modular components: goal function, perturbation, constraint, search method. Operates black-box (API-only), jointly perturbs `[Prompt, example]`, and integrates 17 existing DNN-testing methods plus its own new search method.

Adaptive Beam Search (ABS)

Uses beam search guided by Word Importance Ranking, with two innovations:

  • Adaptive beam width — recomputed each iteration from how many candidates reduced confidence in the ground-truth label.
  • Backtracking — retains a `historicalbest` candidate and can refill the beam with it if the current beam degrades, avoiding permanent loss of good solutions to early greedy mistakes.

Results

5 threat models (Mistral-7B, Llama2-13B, InternLM2-20B, Yi-34B, Llama2-70B) × 3 datasets (Financial Phrasebank, AG’s News, MR) vs. 5 baselines (PWWS, TextFooler, TextBugger, CheckList, StressTest):

  • ABS average success rate 86.1% vs. 68.2% for best baseline (PWWS).
  • Up to 218.8x fewer threat-model queries, up to 3,442 seconds faster per successful test case vs. PWWS.
  • More grammatically natural test cases (5.9 avg. grammatical errors vs. 8.7 for StressTest) and better cross-scale transferability (e.g. 82.3% vs. 76.1% for TextBugger, 13B→70B transfer).
  • Ablation confirms both adaptive width and backtracking independently contribute; combined is best.

Relation to broader wiki

Extends adversarial/robustness testing (Szegedy et al., TextAttack, PWWS, TextFooler, CheckList) from DNN classifiers to LLM-based software, arguing against prompt-only robustness work (e.g. PromptBench) — prompt and example must be tested jointly. See Adversarial Robustness Testing for the framing relative to MMT4NL’s perturbation-based MRs.

Successor: ABFS (Xiao et al. 2026) keeps the same joint prompt+example framing and combinatorial-optimization structure but replaces Adaptive Beam Search with Best-First Search over a confidence-keyed priority queue (global rather than beam-local exploration) plus a history-aware adaptive Word Importance Ranking.
